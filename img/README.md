# Tank képek

Ide kerülnek a tankok képei. **Kódot nem kell szerkesztened** — az app magától
megkeresi a képet a tank id-je alapján.

## Hogyan adj hozzá képet

Mentsd a képet ebbe a mappába, a tank id-jével elnevezve. Ennyi.

| Tank        | fájlnév          |
|-------------|------------------|
| IS-3        | `is-3.jpg`       |
| Tiger II    | `tiger-ii.jpg`   |
| T32         | `t32.jpg`        |
| T-44        | `t-44.jpg`       |
| AMX 50 100  | `amx-50-100.jpg` |

`.jpg`, `.jpeg`, `.png` és `.webp` kiterjesztést is elfogad. Ha egy kép
hiányzik vagy nem tölt be, az app csendben visszaesik a rajzolt sziluettre —
nem törik el, és nem kell mindet egyszerre feltöltened.

## Telefonról, git nélkül

1. Nyisd meg a repót a github.com-on (mobil böngészőben is megy)
2. Lépj be az `img` mappába
3. **Add file → Upload files**
4. Válaszd ki a képeket, majd **Commit changes**

A GitHub Pages 1-2 percen belül frissül.

## Méret

Elég egy ~600 px széles kép; oldalnézet a legjobb a felismeréshez. Nagy
fájlokat ne tegyél be, mert a service worker offline-ra cache-eli őket.

## Jogi megjegyzés

Ha a repo publikus, figyelj rá, mit töltesz fel: a World of Tanks hivatalos
renderei a Wargaming szerzői jogát képezik. Saját használatra rendben van,
publikus terjesztéshez inkább közkincs / Creative Commons fotót keress — a
valódi járművekről a Wikimedia Commons-on bőven van.
